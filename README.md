# React Notes App 📝

A simple notes app built using React to practice useState, form handling, and basic CRUD operations.

## 🚀 Features
- Add notes with title and details
- Delete notes
- Simple and clean UI

## 🛠️ Tech Used
- React (useState)
- Tailwind CSS

## 📚 What I Learned
- Managing state using useState
- Handling form inputs in React
- Rendering lists using map()
- Basic CRUD operations in React
